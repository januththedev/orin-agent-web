Introduction

Orin Agent is for work you assign, not questions you ask. Give it a goal and it plans multi-step tasks, uses tools, interacts with the browser, asks for approval where it matters, and delivers artifacts you can review.

How it works

  • Planning — breaks your goal into steps before acting.
  • Tool use — runs commands, reads and writes files, browses.
  • Approvals — pauses for your decision on consequential actions.
  • Artifacts — results land as files and summaries, not chat bubbles.

The agent runs through a self-hosted gateway on your machine — see Self-hosting.
